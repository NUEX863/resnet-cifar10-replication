# ResNet 论文复现项目

本项目是 MIAE01 Machine Learning Programming and Tools 课程的期末任务 Research Paper Replication。小组选择 He 等人在 CVPR 2016 发表的《Deep Residual Learning for Image Recognition》，复现范围集中在 CIFAR-10 图像分类。ImageNet 和 COCO 的大型实验不在本项目范围内。[论文原文](https://arxiv.org/pdf/1512.03385) · [PyTorch 参考实现](https://github.com/akamaster/pytorch_resnet_cifar10)

| 模型与训练负责人 | 实现模型与训练流程，运行对照和扩展实验，将配置、日志和结果交给搭档分析 | NVIDIA GeForce RTX 5080 Laptop GPU，约 16 GB 显存（驱动报告 16,303 MiB） |

项目使用两位成员的本地设备，不使用云端 GPU。课程文件规定每组三人，目前实际有两名成员，是否需要补充第三人仍待确认。

## 实验计划与结果记录

1. **基线实验**：优先训练 CIFAR-10 上的 ResNet-20。使用至少三个不同的随机种子，记录每次运行的结果，再汇总均值和标准差。
2. **对照实验**：在相同深度、数据处理和训练设置下比较 Plain Network 与 ResNet，观察加入残差连接后训练误差和测试误差的变化。根据本地硬件实测的显存和耗时，决定是否增加 56 层模型。
3. **独立扩展实验**：完成一项扩展实验，具体问题与方案待定。确定方案时写明比较对象、改变的因素和评价指标。

每次运行记录模型、随机种子、数据预处理、训练超参数、实际硬件、运行日志和评估指标。分析时将实测指标与论文中同一模型、同一数据集的指标对齐，并说明训练设置和结果的差异。只有具备运行日志和评估结果的实验才能标为已完成。

## 当前阶段与目录约定

截至 2026-11-08，模型与训练负责人已在 RTX 5080 笔记本上验证独立 Conda 环境，使用 Python 3.11.18、PyTorch 2.10.0+cu128、torchvision 0.25.0+cu128 和 CUDA 12.8 运行时。

[ResNet-20 模型](../src/resnet.py) 有 269,722 个可训练参数。模型已用 8 张模拟图片（RGB，32 × 32）在 GPU 上完成前向传播、反向传播和一次 SGD 参数更新。真实 CIFAR-10 基线实验尚未开始。下一步是接入数据，跑 1 个 epoch 验证训练和评估流程，记录耗时与峰值显存，再确定完整训练范围。

数据与仓库负责人当前的优先事项是编写初版 README、提供 CIFAR-10 下载脚本并配置 `.gitignore`。

- `scripts/` 存放数据准备脚本和运行入口。
- `src/` 存放核心模型定义和训练功能。
